# icons

Tile glyphs for the launcher: `app-<id>.svg` for every id in `web/apps.json` — notes, tasks, calendar, jakestagram, jaketube, jakegpt, habits, period, files, weather, server, settings. 64x64 viewBox, white strokes (width 4) / fills on transparent, simple geometric shapes, no gradients, no text, no emoji; drawn at 56% of the 60px tile. `icon-180.png`, `icon-512.png`, `favicon.png` are the app icon from v1.
